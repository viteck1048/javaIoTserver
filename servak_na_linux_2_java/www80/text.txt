# Ласкаво просимо на наш сервер!

Це головна сторінка мого Java сервера. Тут ви можете знайти корисні ресурси та документацію.

## Доступні функції

- **Вхід та реєстрація користувачів** - через форму авторизації
- **Перегляд документів** - переходьте на вкладку "Документи"
- **Прокси-сервер** - для доступу до зовнішніх ресурсів

## Про проект

Це проект Java-сервера, який включає:

1. HTTP-сервер з базовими функціями
2. Механізм автентифікації користувачів
3. Зворотній проксі для обробки запитів
4. Підтримку різних типів контенту

Оберіть відповідний розділ у верхньому меню для доступу до потрібних функцій.
