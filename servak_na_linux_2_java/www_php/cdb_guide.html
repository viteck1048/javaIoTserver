📖 🔥 Повна шпаргалка по CDB / GDB

Повна шпаргалка по CDB (консольний WinDbg) та GDB — основні команди для дебагу:

📌 📦 Процес / виконання:

CDB GDB Опис
g continue Продовжити виконання
Ctrl+Break Ctrl+C Призупинити виконання
q quit Вийти з дебагера
.restart run Перезапустити дебагований процес
.kill kill Завершити процес
.detach detach Відʼєднатись від процесу

📌 📦 Модулі:

CDB GDB Опис
lm info sharedlibrary Список завантажених модулів
lmf (немає) З повними шляхами
lml (немає) Короткий список

👉 Приклад:

0:000> lm

📌 📜 Памʼять:

CDB GDB Опис
db <addr> x/<n>b <addr> Вивести байти
dw <addr> x/<n>h <addr> Вивести слова
dd <addr> x/<n>w <addr> Вивести DWORD
dq <addr> x/<n>g <addr> Вивести QWORD
eb <addr> <val> set {char}<addr> = <val> Записати байт
ed <addr> <val> set {int}<addr> = <val> Записати DWORD
!address info proc mappings Мапінг віртуальної памʼяті
!vadump (немає) VAD-дерево (Windows-only)

👉 Приклад:

0:000> !address

📌 📌 Брейкпоінти:

CDB GDB Опис
bp <addr> break <addr> Поставити брейкпоінт
bl info breakpoints Список брейкпоінтів
bc <n> delete <n> Видалити брейкпоінт
bc * delete Видалити всі
bd <n> disable <n> Вимкнути брейкпоінт
be <n> enable <n> Увімкнути брейкпоінт
ba e <addr> watch <addr> Watchpoint на запис
ba w <addr> watch <addr> Watchpoint на читання
ba r <addr> (немає прямого аналога) Watch на виконання

📌 📂 Потоки:

CDB GDB Опис
~ info threads Список потоків
~0s thread 1 Перемкнутись на потік
~*k (немає прямого аналога) Стек трейс всіх потоків

📌 Приклад задачі:

1. Запустив програму

cdb myapp.exe

2. Після старту натиснув Ctrl+Break — призупинив

3. Подивився модулі

0:000> lm

4. Подивився віртуальні адреси

0:000> !address

5. Продовжив

0:000> g

📌 📝 Підказка:

CDB GDB Опис
.help help Загальна довідка
.help <cmd> help <cmd> Про команду

📌 📋 Регістри:

CDB GDB Опис
r info registers Показати регістри
r <reg>=<val> set $<reg>=<val> Змінити регістр

📌 📜 Стек трейси:

CDB GDB Опис
k bt Стек трейc
kv bt full Стек з параметрами
k <n> bt <n> N кадрів стека

📌 📚 Дизасемблер:

CDB GDB Опис
u <addr> disas <addr> Дизасемблер
uf <addr> disas /m <func> Дизасембл функції

📌 📄 Символи:

CDB GDB Опис
x <module>!* info functions Перелік всіх символів
x <mod>!FuncName info address <FuncName> Адреса символу
